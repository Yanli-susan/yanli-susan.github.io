# Yan Li (Susan) — Personal Academic Homepage

Source code of my personal homepage: https://yanli-susan.github.io/

- `index.md` — page content (about, research interests, publications, working papers, projects)
- `_config.yml` — site title, contact info, SEO metadata, and links (Google Scholar, CV)
- `assets/` — CV (PDF), avatar, favicons, CSS and JS

The site is built automatically by GitHub Pages (Jekyll) on every push to `main`.

## Credits

Built on the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme by Yaoyao Liu, which is based on [minimal](https://github.com/orderedlist/minimal).
